## 📖 About

**SEM** stands for **Software Engineering Methods**.

This repository contains the implementation and development work for a Java-based Software Engineering project.

The project is structured around standard software development practices including:

- ☕ Java development
- 📦 Maven project management
- ⚙️ Automated builds with GitHub Actions
- 🐳 Docker containerisation
- 🔀 Git-based version control
- 🧪 Automated project verification

The project is intended to demonstrate practical software engineering concepts, development workflows and modern tooling.
